# مكتبة الوراق | Al-Warraq Library

مشروع كامل: **واجهة أمامية** (HTML/CSS/JS بلا بناء) + **خادم** (Python FastAPI) + **قاعدة بيانات** (SQLite).
يعرض فهرساً بحجم **كل فهرس غوتنبرغ (نحو 75,000 كتاب)** من مشروع غوتنبرغ (ملك عام) مع تصنيفات ومؤلفين مشهورين،
وقسماً لروابط البحوث الطبية والهندسية المفتوحة. الواجهة بالعربية والإنجليزية.

```
backend/
  app/main.py        واجهة API وتقديم الموقع
  app/db.py          قاعدة SQLite والبيانات المنتقاة (386 كتاباً، 146 مؤلفاً)
  app/importer.py    استيراد فهرس غوتنبرغ الرسمي
  app/bootstrap.py   يعمل قبل الخادم: إنشاء الجداول + الاستيراد لأول مرة
  app/research.py    مصادر البحوث الطبية والهندسية
  app/data/          authors.txt و books.txt (قابلة للتعديل)
  tests/             اختبارات الـ API والاستيراد
frontend/            index.html + style.css + app.js
Dockerfile, docker-compose.yml
```

## التشغيل بـ Docker (الأسهل)
```bash
docker compose up -d --build
```
افتح http://localhost:8000. عند أول تشغيل ينزّل الخادم فهرس غوتنبرغ (يحتاج إنترنت) ويستورد كل الكتب
(يستغرق نحو دقيقة). البيانات تُحفظ في volume باسم `warraq-data` فلا يتكرر الاستيراد.

## التشغيل بدون Docker
```bash
./run_local.sh          # يحتاج Python 3.9+
```

## النشر على الإنترنت
- **سيرفر (VPS) + نطاق:** شغّل `docker compose up -d --build` ثم ضع Caddy أمامه:
  ```
  library.example.com {
      reverse_proxy localhost:8000
  }
  ```
  (Caddy يجلب شهادة HTTPS تلقائياً.)
- **Railway / Render / Fly.io:** انشر المستودع كخدمة Docker، وأضف قرصاً دائماً (volume) مُركَّباً على `/data`.
  المنصة تضبط `PORT` تلقائياً والـ Dockerfile يقرأه.

## إعدادات (متغيرات بيئة)
| المتغير | الافتراضي | الوصف |
|---|---|---|
| `AUTO_IMPORT` | `1` | استيراد غوتنبرغ عند أول تشغيل |
| `IMPORT_LIMIT` | `0` | عدد الكتب (0 = الكل) |
| `IMPORT_LANGS` | (الكل) | تقييد اللغات، مثل `en,ar,fr` |
| `WARRAQ_DB` | `backend/data/warraq.db` | مسار قاعدة البيانات |

إعادة الاستيراد أو تغيير العدد يدوياً:
```bash
cd backend && python -m app.importer --lang en,ar
# أو من ملف نزّلته: python -m app.importer --csv pg_catalog.csv
```
الاستيراد آمن للتكرار: يستبدل الكتب المستوردة فقط ويُبقي المنتقاة.

## واجهة API
| المسار | الوصف |
|---|---|
| `GET /api/books?q=&cat=&org=&ak=&sort=def\|t\|a&bl=&ui=ar\|en&offset=&limit=` | بحث وتصفية وترقيم الصفحات |
| `GET /api/meta` | التصنيفات والمؤلفون مع الأعداد |
| `GET /api/shelf` | كتب رف الغلاف في الصفحة الرئيسية |
| `GET /api/research?domain=med\|eng&q=` | روابط بحث جاهزة في قواعد البحوث المفتوحة |
| `GET /api/cover/{id}` | غلاف من المكتبة المفتوحة (يُحفظ في القاعدة) |
| `GET /api/health` | فحص الحالة |

وثائق تفاعلية: `/docs`.

## ملاحظات قانونية
- الموقع لا يستضيف ملفات كتب. كل رابط يقود إلى المصدر الأصلي (غوتنبرغ، أرشيف الإنترنت، المكتبة المفتوحة، ويكي مصدر، وقواعد الأبحاث).
- الملك العام يختلف من بلد لآخر (غوتنبرغ يتبع القانون الأمريكي). راجع قانون بلدك قبل أي إعادة نشر.

## الأغلفة
الكتب التي لها رقم في غوتنبرغ تُحمَّل أغلفتها مباشرة من غوتنبرغ. وإن لم يوجد غلاف يسأل المتصفح الخادم،
فيبحث في المكتبة المفتوحة (Open Library) مرة واحدة ويحفظ النتيجة لكل الزوار. وإن لم يوجد شيء يظهر غلاف مصمَّم باسم الكتاب.

## ترقية من نسخة سابقة
احذف الملف `backend/data/warraq.db` ثم شغّل `python -m app.bootstrap` من جديد، فيعاد بناء القاعدة بالفهرس الكامل.

## الوصول إلى 500 ألف كتاب (HathiTrust)
غوتنبرغ وحده نحو 75,000 كتاب. لإضافة مئات الآلاف:
1. من صفحة https://www.hathitrust.org/hathifiles نزّل ملف الفهرس الكامل `hathi_full_YYYYMMDD.txt.gz` (نحو 1 جيجابايت، لا تفكّه).
2. ضعه في مجلد المشروع، ثم من داخل `backend`:
```bash
python -m app.importer --hathi ../hathi_full_20260101.txt.gz --hathi-limit 450000
```
يقرأ الملف على دفعتين ولا يحتاج ذاكرة كبيرة، ويأخذ بضع دقائق. يضيف الكتب المتاحة للعرض الكامل في العالم كله فقط
(`access=allow` و`rights=pd`) ويتجاوز المكرر وما هو موجود من غوتنبرغ.
مع Docker: ضع الملف في مجلد المشروع وفعّل في `docker-compose.yml` السطرين `HATHI_FILE` و`volumes` الموضحين فيه.

> الأغلفة من HathiTrust تُجلب من رابط الغلاف الرسمي عندهم، وإن لم تظهر يستخدم الموقع المكتبة المفتوحة ثم الغلاف المصمَّم.
